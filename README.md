# Solar-Powered Desalination System

## Description
A small-scale solar desalination system designed to produce clean water from saltwater using solar energy. Suitable for educational demonstrations.

## Features
- Solar-powered operation
- Low-cost materials
- Simple design for easy replication

## How It Works
Water is heated by solar energy, evaporated, and condensed into clean water.

## Components
- Solar panel
- DC water pump
- Glass cover
- Black tray for heating
- Water container

## Applications
- Remote areas
- Education and STEM projects
